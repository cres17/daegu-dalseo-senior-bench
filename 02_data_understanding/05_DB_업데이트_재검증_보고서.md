## 2. 새로 사용 가능해진 데이터

### 행정동 경계

- 전국 경계 SHP와 DBF 레코드가 3,559건으로 일치한다.
- 센서스 달서구 코드 접두어 `22070`으로 23개 행정동이 식별된다.
- 노인인구표의 23개 동명과 정규화 기준 23/23 일치한다.
- 최신 코드 워크북의 달서구 23개 코드와 경계 DBF가 23/23 일치한다.
- 기준일은 2025-06-30이고 중복 행정동 코드는 없다.

따라서 행정동별 고령인구 분포 지도와 시설의 행정동 공간조인은 진행할 수 있다. 다만 센서스 코드 `22070...`와 공공데이터의 최신 시군구 코드 `27290`은 서로 다른 체계이므로 명시적 변환표 없이 혼용하지 않는다.

### 안전·보행 보조자료

- 노인보호구역: 5개 위치
- 달서구 보행자전용도로 CSV: 7행, 고유 구간 3개
- 육교: 10개 시설, 고유 좌표 9개
- 대구 횡단보도: 17,573개 면형 객체
- 도시계획 대구 객체: 공공보행통로 15개, 보행자우선도로 1개, 보행자전용도로 9개

이 자료들은 안전성과 특정 보행시설의 존재를 보완하는 데는 쓸 수 있지만, 일반 보도·골목·연결관계를 포함하지 않으므로 경로계산의 기본 네트워크로는 사용할 수 없다.

## 4. 좌표계와 공간조인 주의사항

- 행정동 경계: KGD2002 Central Belt 2010
- 횡단보도·버스 공간정보: Korea 2000 East Belt 2010
- 도시계획 보행 레이어: Korean 1985 / Modified Central Belt, EPSG:5174
- 시설 CSV: WGS84 위·경도

네 좌표체계를 하나의 미터 단위 분석좌표계로 변환하기 전에는 최근접거리·교차·포함 여부를 계산하지 않는다. 특히 도시계획 레이어는 달서구 속성키가 없어 정확한 공간조인이 필수다.

## 5. 현재 가능한 분석과 다음 게이트

현재 가능한 작업은 행정동별 고령인구 지도, 시설·정류소·휴식시설·보호구역·육교 분포, 횡단보도와 지정 보행구간의 달서구 공간필터 준비다.

다음 단계에 진입하기 위한 핵심 잔여 조건은 다음과 같다.

1. OSMnx `walk` 네트워크 생성 및 단절·누락 표본검수
2. 경로당 좌표 이상 3건 보정
3. 정류소 568개의 `bs_id` 교차표 확정
4. 공원 집계 벤치와 개별 벤치 위치 분리
5. 서로 다른 공간자료의 좌표계 통일

이 조건을 충족한 뒤에만 보행 최단경로, 경로 중첩도, 300m·500m 벤치 공백 분석으로 넘어간다.
