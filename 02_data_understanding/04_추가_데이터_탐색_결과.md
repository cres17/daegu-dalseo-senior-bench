# 추가 데이터 탐색 결과

- 단계: Data Understanding
- 버전: v0.2 (확보상태 재검토)
- 탐색일: 2026-07-22
- 원칙: 공식·1차 출처를 우선하며, 다운로드 가능 여부·공간단위·라이선스는 실제 확보 시 다시 확인한다.

## 1. 우선 확보 권고

### 확보 완료: 행정동 경계

센서스 행정동 경계와 코드 워크북이 추가됐다. 2025년 6월 기준 달서구 23개 경계가 노인인구표 23개 동과 정규화 명칭 기준으로 모두 일치하고, 워크북 코드도 DBF와 23/23 일치한다. 따라서 행정동 경계는 추가 확보 대상에서 제외하고 좌표계 변환·공간조인 준비 대상으로 전환한다.

### 참고: 행정경계 공식 출처

공공데이터포털의 전국 시군구 경계 데이터에는 달서구 코드와 경계가 포함된다. 다만 프로젝트에는 행정동 23개 경계가 더 중요하므로 시군구 경계만 받는 것으로는 부족하다. 행정동 경계는 SGIS 또는 통계지리정보서비스 자료를 우선 검토한다.

- 후보: [공공데이터포털 시군구 경계](https://www.data.go.kr/data/15149185/fileData.do?recommendDataYn=Y)
- 후보: [SGIS 통계지리정보서비스](https://sgis.mods.go.kr/)
- 확보 조건: 행정동 코드·명, Polygon, 기준연도, 좌표계, 달서구 23개 동 대응표

### 1순위: 보행 가능 도로망

OSMnx는 폴리곤 안의 `walk` 네트워크를 내려받고 최단경로·고도·경사 속성을 처리할 수 있어 1차 보행망 생성에 적합하다. 다만 `walk` 필터에는 보행 가능한 서비스도로·주차통로도 포함될 수 있고 OSM 누락 정도가 지역별로 다르므로 주요 경로와 단절 구간을 표본 검수해야 한다.

- 후보: [OSMnx 공식 문서](https://osmnx.readthedocs.io/en/stable/getting-started.html)
- 보행망 생성: [OSMnx `graph_from_polygon`·routing 문서](https://osmnx.readthedocs.io/en/stable/user-reference.html?highlight=shortest_path)
- 태그 검토: [OpenStreetMap Sidewalks](https://wiki.openstreetmap.org/wiki/Sidewalks)
- 라이선스: [OpenStreetMap 저작권·ODbL](https://www.openstreetmap.org/copyright/sp)
- 확보 조건: 달서구 경계보다 충분한 버퍼를 둔 뒤 생성, 일방통행·계단·횡단·접근제한·단절 검수, 출처표시

### 2순위: 세부 고령인구

SGIS 집계구 통계 API와 자료제공 기능을 활용하면 행정동보다 작은 공간단위의 65세 이상 인구를 검토할 수 있다. SGIS API 정의에서 65세 이상 연령 코드는 24로 제시되며, 집계구는 대체로 약 500명 규모의 소지역이다. 제공연도·비밀보호 처리·API 인증·이용조건을 실제 취득 전에 확인해야 한다.

- 후보: [SGIS 집계구 통계 API](https://sgis.mods.go.kr/OpenAPI2/contents/sub03.vw)
- 정의: [SGIS Data API 정의서](https://sgis.kostat.go.kr/developer/upload/doc/DataAPI-definition.pdf)
- 집계구 설명: [SGIS 도움말](https://sgis.mods.go.kr/view/newhelp/us_help_10_0)
- 확보 조건: 65세 이상 코드, 기준연도, 집계구 경계/코드, 통계값의 결측·비밀보호 상태

## 2. 안전성과 경사 보완자료

### 횡단보도·보행안전시설

대구 횡단보도 면형 위치 17,573건이 추가됐지만 속성은 객체 ID, 공사구분·공사일뿐이며 행정구·신호기·교통섬·보도턱 낮춤·점자블록·조명이 없다. 달서구 경계 공간조인 후 위치 레이어로는 쓸 수 있으나, 고령친화 안전성은 전국횡단보도표준데이터로 보완해야 한다.

- 후보: [전국횡단보도표준데이터](https://www.data.go.kr/data/15028201/standard.do?recommendDataYn=Y)
- 확보 조건: 달서구 필터, 최신 기준일, 좌표 누락, 시설 속성 정의와 갱신주기 확인

### 노인보행자 사고다발지역

한국도로교통공단 자료는 65세 이상 보행노인 사고다발지역을 제공한다. 2021년 이후 선정기준은 최근 3년간 사망·중상 사고와 반경 100m 기준이므로, 점수에 직접 합산하기 전에 집계기간과 선정기준을 명시해야 한다.

- 후보: [한국도로교통공단 보행노인 교통사고 다발지역](https://www.data.go.kr/dataset/15003493/fileData.do?lang=ko)
- 확인도구: [TAAS 교통사고분석시스템](https://taas.koroad.or.kr/)
- 정의 확인: [TAAS 교통사고 용어정리](https://taas.koroad.or.kr/sta/acs/exs/wordArngPopup.do)
- 확보 조건: 65세 이상 보행자, 분석연도, 중심좌표/영역, 사고건수, 사망·중상 기준

### 도로 경사도

국토지리정보원 수치표고모형은 고도 자료 확보 후보이다. 보행 링크 양끝 고도를 부여해 `고도차/링크길이`로 경사도를 계산할 수 있으나, 해상도와 건물·교량 영향, 수직기준을 확인해야 한다.

- 후보: [국토지리정보원 수치표고모형](https://www.data.go.kr/data/15059920/fileData.do)
- 확보 조건: 달서구 커버리지, 해상도, 수평·수직 좌표계, 결측, 사용허가

## 3. 보조·검증용 자료

전국보행자전용도로표준데이터는 지정된 보행자전용도로를 확인하는 데 유용하지만, 모든 보도·골목을 포함하는 완전한 보행 네트워크는 아니다. OSM 보행망의 일부 구간을 보완·검증하는 용도로만 사용한다.

- 후보: [전국보행자전용도로표준데이터](https://www.data.go.kr/data/15025443/fileData.do)

달서구 주민등록 월별 인구 현황은 총인구·세대수와 고령인구의 분모를 맞추거나 고령인구 비율을 계산하는 보완자료가 될 수 있다. 현재 보유한 노인인구 파일에는 고령인구 합계만 있으므로, 절대수와 비율을 모두 제시하려면 필요하다.

- 후보: [달서구 주민등록 월별 인구 현황](https://www.data.go.kr/data/15059790/fileData.do)

## 5. 취득 후 즉시 확인할 항목

1. 출처, 기준일, 이용허락, 갱신주기와 원본 URL을 기록한다.
2. 좌표계와 공간단위를 확인하고 달서구 커버리지를 지도에서 검수한다.
3. 행정동 코드·정류소 ID처럼 지속 가능한 키를 우선한다.
4. OSM 보행망은 주요 시설 주변, 하천·철도·고속도로 횡단, 단절구간을 표본점검한다.
5. 65세 이상 통계는 연령코드·기준연도·비밀보호 값을 확인한다.
6. 사고·횡단보도·DEM은 분석점수에 바로 넣지 않고 결측과 최신성을 먼저 평가한다.
