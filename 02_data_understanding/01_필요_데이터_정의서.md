# 필요 데이터 정의서

- 프로젝트: 달서구 고령자 예상 보행수요 기반 벤치 설치 우선 검토 구간 분석
- 단계: Data Understanding
- 버전: v0.2 (DB 업데이트 재검증)
- 작성일: 2026-07-22

## 1. 데이터 범위와 공통 정의

- 분석지역은 대구광역시 달서구이며 서구 벤치 자료는 1차 분석에서 제외한다.
- 고령자는 만 65세 이상으로 정의한다.
- 휴식시설 공급은 `벤치`와 `버스정류장 의자`만 포함한다. 의자 수가 0인 관측치는 공급이 아니라 확인된 미설치 상태로 본다.
- 분석 결과는 실제 고령자 이동경로나 최종 설치점이 아니라 `예상 보행수요`와 `설치 우선 검토 구간`이다.
- 벤치 공백 기준은 보행 네트워크 거리 300m와 500m 두 시나리오로 분석한다. 직선거리 결과는 검산·설명용으로만 사용한다.
- 버스 이용량은 전 연령 이용량이며, 고령자 이용량으로 표현하지 않는다.
- 버스 노선 공간정보는 대중교통 연결성 참고자료이며 보행망으로 사용하지 않는다.

## 2. 분석 단위와 기준 시점

| 항목 | 기준 |
|---|---|
| 수요 공간단위 | 1차: 행정동, 개선안: 집계구 또는 100m 격자 |
| 시설 공간단위 | 시설별 점 위치 |
| 정류소 기준키 | 버스 공간정보의 `bs_id`를 마스터키로 사용하되 위치 CSV와 검증된 교차표 필요 |
| 보행 분석단위 | 보행 가능 도로 링크 및 일정 간격 샘플 지점 |
| 휴식 공급단위 | 의자 수가 1개 이상인 벤치·버스정류장 의자 위치 |
| 공원 벤치 단위 | 2026년 공원별 집계와 2022년 개별 좌표를 분리 관리 |
| 버스 대표기간 | 2025년 12개월 시간대별 자료를 주 분석기간 후보로 하고 2024년을 민감도 비교기간으로 검토 |
| 좌표계 | 원본 좌표계 유지 후 Data Preparation에서 미터 단위 투영좌표계로 통일. 버스 SHP의 제공 WKT와 EPSG 대응은 변환 전 검증 |

## 4. 데이터별 수용 기준

| 데이터 | 최소 수용 기준 | 수용 불가 또는 보류 조건 |
|---|---|---|
| 행정경계 | 달서구 23개 행정동과 인구표 동명이 결합되고 CRS 확인 가능 | 법정동 경계만 있고 행정동 변환표가 없음 |
| 보행망 | 보행자 통행 가능 링크, 길이, 연결성, 달서구 완전 포함 | 차량전용도로 중심이거나 단절·누락 검증이 없음 |
| 고령인구 | 만 65세 이상이라는 원자료 정의 확인 | 단순 총인구이거나 연령 기준 불명확 |
| 시설 위치 | 달서구 범위 내 좌표, 유형·기준일 확인 | 주소와 좌표 모두 없거나 좌표가 지역 밖인데 미보정 |
| 버스 이용량 | 정류소 ID 또는 검증된 교차표로 위치와 결합 | 정류소명만으로 중복·개칭을 해소하지 못함 |
| 휴식시설 | 벤치 또는 정류장 의자이며 양수 개수와 위치 확인 | 0개, 실내 의자, 공원 대표점에 총개수를 중복 배치 |
| 사고자료 | 65세 이상 보행자 기준과 집계기간 명시 | 전체 사고를 노인보행 사고로 대체 |
| 경사도 | 보행 링크와 동일한 투영좌표계에서 고도차/길이 산출 | DEM 해상도·수직기준 불명확 또는 링크 길이 0 |

## 5. 현재 데이터로 가능한 것과 불가능한 것

현재 데이터로 행정동 경계 기반 고령인구 지도, 시설·정류소·기존 휴식시설의 점 분포, 전 연령 버스 이용량 비교, 노인보호구역·횡단보도·육교·지정 보행구간의 보조 레이어 구축이 가능하다. 그러나 신규 보행자료는 일부 지정구간 또는 면형 시설목록이며 완전한 연결형 보행망이 아니다. 따라서 예상 최단경로, 경로 중첩도, 네트워크 기준 300m·500m 벤치 공백, 최종 TOP N 산정은 OSMnx 등의 보행망을 생성·검수하기 전까지 수행하지 않는다.
