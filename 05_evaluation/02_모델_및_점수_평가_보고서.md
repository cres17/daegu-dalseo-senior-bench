# 예상 보행 수요·벤치 공백 모델 및 점수 평가

## 1. 평가 질문

1. 분석이 실제 GPS가 아닌 예상 보행 수요라는 범위를 지키는가?
2. 고령인구·시설·정류장과 연결된 구간이 후보가 되는가?
3. 좌석이 충분한 구간이 후보에서 제외되는가?
4. 거리·가중치·계단 처리 변화에도 후보가 유지되는가?
5. 현재 결과를 실제 설치 결정에 사용할 수 있는가?

## 2. 계산 검증

Evaluation 자동검증 EV-01~EV-10은 모두 통과했다.

- Modeling PASS 결과 사용
- 36개 민감도 조합 생성
- 모든 조합에서 TOP 20 산출
- 800m·수요 50% 재계산 결과와 Modeling TOP 20 일치
- 점수 범위 0~1
- 좌석 충분 도로 후보 제외
- 기존 후보 39개 모두 목적지 근거 보유
- 300m·500m 현장조사 후보 각 15개
- 현장조사 후보 좌표 완전
- 두 기준 모두 안정 후보 존재

## 3. 점수 구조 평가

현재 점수는 수요 백분위와 공백 백분위의 기하평균이다. 어느 한 요소만 높은 도로가 상위권을 과도하게 차지하지 않도록 설계됐다.

민감도 평가에서는 수요 비중을 35~65%로 변경했다. 800m 반경 안에서는 TOP 20 유지율이 85~90%여서 현재 결과가 단일 가중치에만 의존한다고 보기는 어렵다.

다만 OD 반경 변경 시 유지율이 최저 50%로 내려간다. 핵심 불확실성은 가중치보다 **예상 생활권을 몇 m로 볼 것인가**에 있다.

## 4. 안정성 분류

| 분류 | 기준 | 용도 |
|---|---|---|
| `STABLE_2_OF_3_PLUS` | 18개 중 12개 이상 TOP 20 | 우선 현장조사 |
| `CONDITIONAL_1_OF_3_PLUS` | 18개 중 6~11개 | 조건부 후보 |
| `SENSITIVE_BELOW_1_OF_3` | 18개 중 5개 이하 | 특정 가정 의존 후보 |

이 기준은 통계적 유의성 기준이 아니라 현장조사 대상을 줄이기 위한 운영 규칙이다.

## 5. 순위 성격

선택된 조합의 평균 수요·공백 백분위 차이를 이용해 후보 성격을 보조적으로 표시했다.

- `BALANCED`: 수요와 공백 근거가 비슷함
- `DEMAND_LED`: 수요 근거가 상대적으로 강함
- `GAP_LED`: 좌석 공백 근거가 상대적으로 강함

300m 안정 후보 16개 중 14개는 `BALANCED`였다. 500m 안정 후보 15개 중 5개는 `GAP_LED`로, 실제 보행 수요 확인이 특히 중요하다.

## 6. 데이터 품질과 의사결정 위험

### High

- 공원 개별 벤치가 2022년 자료
- 버스 이용량이 전체 연령 자료
- 좌석의 현존·상시 이용 가능 여부 미확인
- 경사·횡단안전·보도 폭·설치 가능성 미포함

### Medium

- 정류소 568개 중 6개 이용량 ID 미확정
- 점-보행망 스냅 거리 100m 초과 88건/시나리오

### Low

- 보행망 수동판정 50건 중 46건의 확인 출처 미기입

## 7. 최종 평가

| 사용 목적 | 판정 |
|---|---|
| 공모전 문제정의와 후보 선별 근거 | 사용 가능 |
| 현장조사 대상 선정 | 사용 가능 |
| 고령자의 실제 이동경로 주장 | 사용 불가 |
| 실제 설치 순서 확정 | 사용 불가 |
| 최종 설치 위치 확정 | 사용 불가 |

최종 신뢰도는 `Share with caveats`다. 현장조사 결과가 들어오면 안전성과 설치 가능성을 포함한 2차 평가를 수행해야 한다.
