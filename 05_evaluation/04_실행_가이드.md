# Evaluation 실행 가이드

## 1. Evaluation 재실행

프로젝트 루트에서 실행한다.

```bash
python3 -m pip install -r 05_evaluation/requirements-evaluation.txt
python3 05_evaluation/scripts/evaluate_priority_candidates.py
```

## 2. 재현 노트북 실행

```bash
/Users/moon/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 \
  05_evaluation/scripts/execute_evaluation_notebook_stdlib.py
```

## 3. 보고서 데이터 재생성

```bash
python3 05_evaluation/scripts/build_evaluation_report_artifact.py
```

## 4. 성공 여부 확인

- `05_evaluation/qa/evaluation_summary.json`: `status=PASS`
- `05_evaluation/qa/evaluation_validation_checks.csv`: EV-01~EV-11 모두 PASS
- 실행된 노트북의 error output: 0건

## 5. 주요 산출물

| 파일 | 용도 |
|---|---|
| `consensus_candidates_by_threshold.csv` | 기준별 민감도 합의 후보 전체 |
| `field_review_priority_and_template.csv` | 실제 현장조사 입력표 |
| `baseline_top20_sensitivity_comparison.csv` | 기준 순위 유지율 |
| `step_scenario_top20_comparison.csv` | 계단 포함·제외 후보 비교 |
| `candidate_evidence_coverage.csv` | 시설·인구 연결 근거 포함률 |
| `sufficient_supply_exclusion_checks.csv` | 좌석 충분 도로 제외 검사 |
| `decision_data_quality_risks.csv` | 설치 결정 전 품질 위험 |
| `evaluation_report_artifact.json` | 검증된 분석 보고서 원본 |
| `field_review_app/index.html` | 54개 고유 도로의 지도·현장조사 입력 화면 |

54개 통합 검토 화면을 다시 만들 때는 다음을 실행한다.

```bash
python3 05_evaluation/scripts/prepare_expanded_field_review.py

```

첫 번째 스크립트는 기존 완료 CSV에서 29개 판정을 불러오고, 아직 검토하지
않은 25개를 추가하여 `outputs/field_review_54_prefilled.csv`를 만든다.

## 현장조사 완료 후 2차 Evaluation

프로젝트 루트에 `dalseo_field_review_completed*.csv`를 넣은 뒤 실행한다.
파일이 여러 개면 수정시각이 가장 최근인 파일을 사용한다.

```bash
python3 05_evaluation/scripts/integrate_field_review_results.py
python3 05_evaluation/scripts/build_field_review_integration_notebook.py
python3 05_evaluation/scripts/execute_field_review_notebook_stdlib.py
```

주요 산출물:

| 파일 | 내용 |
|---|---|
| `outputs/field_adjusted_priority_candidates.csv` | 현장판정·제외 사유를 포함한 전체 29개 후보 |
| `outputs/field_adjusted_priority_top10.csv` | 현장판정 반영 2차 우선 확인 후보 10개 |
| `outputs/field_adjusted_priority_top10_wgs84.geojson` | 2차 후보의 WGS84 도로 선형 |
| `qa/field_review_quality_findings.csv` | 현장입력 품질·교차 일관성 검사 |
| `qa/field_review_integration_summary.json` | 통합 실행 요약 |
| `06_현장조사_통합_평가_보고서.md` | 2차 Evaluation 해석 보고서 |
| `notebooks/02_field_review_integration.ipynb` | 재현 가능한 검증 노트북 |

Evaluation 다음 단계는 Deployment가 아니라 **현장조사 결과 입력과 2차 평가 여부 결정**이다. 현장조사 없이 설치 가능성 점수를 임의로 만들지 않는다.
