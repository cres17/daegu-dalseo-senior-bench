## v2 현장검수 안전 게이트와 공개 데이터 갱신

완료된 40개 현장검수표는 종합 `review_status`만 신뢰하지 않고 세부 안전
필드와 교차검증한다. 직접 설치 검토군은 기존 좌석 없음, 연속 보도, 설치 후
최협소 유효폭, 허용 가능한 경사, 낮은 횡단 위험, 공공 설치 가능성, 검토자와
검토일이 모두 확인된 후보만 포함한다.

유효폭은 「교통약자의 이동편의 증진법 시행규칙」 별표 1 제3호가목1)을
후보 선별 기준으로 적용한다.

- 원칙: 설치 후 남는 최협소 유효폭 `2.0m 이상`
- 예외: `1.2m 이상 2.0m 미만`은 `width_standard_exception=APPROVED`,
  `width_exception_authority`, `width_exception_basis`,
  `width_exception_reason`을 모두 기록. 예외 근거는 지형상 불가능
  (`TOPOGRAPHY_IMPOSSIBLE`) 또는 기존 도로 증·개축 시 불가피
  (`EXISTING_ROAD_UNAVOIDABLE`) 중 하나만 허용
- 추가 확인: `1.5m 미만`은 50m마다 1.5m×1.5m 이상 교행구역을 확인하고,
  경사진 연속 보도는 30m마다 같은 크기의 수평 참을 확인
- 절대 차단: `1.2m 미만`, 예외 미승인, 추가 시설 미확인

`effective_width_m`은 도로 전체 폭이나 OSM `width`를 복사하지 않는다.
벤치·가로시설 설치 후 보행에만 이용되는 잔여 폭을 가장 좁은 지점에서
실측한다. 현재 입력표에 없는 예외 관련 열은 실행 시 빈 열로 추가되며,
증거가 입력되기 전에는 자동으로 직접 검토군에서 차단된다.

- [현행 시행규칙](https://www.law.go.kr/LSW/lsInfoP.do?lsiSeq=283221)
- [유효폭 정의가 포함된 도로 구조·시설 기준](https://law.go.kr/lsLinkCommonInfo.do?chrClsCd=010202&lsJoLnkSeq=1024181483)
