# 후보구간 현장조사 가이드

## 1. 사용할 화면과 파일

- 입력 화면: `05_evaluation/field_review_app/index.html`
- 고유 도로 원본: `05_evaluation/outputs/field_review_unique_template.csv`
- 기준별 상세표: `05_evaluation/outputs/field_review_priority_and_template.csv`

화면은 민감도 18개 조합 중 6회 이상 선정된 후보를 대상으로, 같은
`physical_id`의 300m·500m 중복을 합쳐 54개를 표시한다. 기존 검토
29개는 판정이 채워져 있고 추가 25개만 미검토 상태다. 입력은 브라우저에
자동 저장되며, 조사 후 `완료 CSV 내보내기`로 결과를 보관한다.

## 2. 확인 순서

1. `field_review_order` 순서대로 조사한다.
2. `kakao_map_url`로 후보 중앙점을 확인한다.
3. 중앙점만 보지 말고 해당 도로 구간 전체를 양방향으로 확인한다.
4. 기존 좌석이 실제로 있는지와 정상 사용 가능한지 확인한다.
5. 보도 연속성, 폭, 경사, 횡단 위험과 설치 가능성을 기록한다.
6. 후보 중앙점보다 적절한 위치가 있으면 조정 내용을 남긴다.

## 3. 입력값

| 컬럼 | 권장 입력값 |
|---|---|
| `review_status` | `INSTALLABLE`, `CONDITIONAL`, `NOT_INSTALLABLE`, `REVISIT` |
| `existing_seat_verified` | `YES`, `NO`, `UNCERTAIN` |
| `continuous_sidewalk` | `YES`, `PARTIAL`, `NO` |
| `effective_width_m` | 현장 실측 또는 추정 폭(m) |
| `slope_condition` | `FLAT`, `MODERATE`, `STEEP`, `UNCERTAIN` |
| `crossing_risk` | `LOW`, `MEDIUM`, `HIGH`, `UNCERTAIN` |
| `shade_weather_protection` | `GOOD`, `PARTIAL`, `NONE` |
| `ownership_installability` | `PUBLIC_LIKELY`, `PRIVATE_LIKELY`, `UNCERTAIN` |
| `recommended_segment_adjustment` | 이동 권고 방향·거리 또는 새 좌표 |
| `review_notes` | 기존 좌석 상태, 불법주정차, 보행 방해 등 |
| `reviewer` | 검토자 |
| `review_date` | `YYYY-MM-DD` |

## 4. 판정 원칙

### INSTALLABLE

- 연속된 보행공간이 있음
- 좌석 설치 후 유효 보행 폭을 확보할 수 있음
- 횡단이나 차량 충돌 위험이 낮음
- 공공 설치 가능성이 높음

### CONDITIONAL

- 후보 필요성은 있으나 위치 이동, 폭 확보, 관계기관 협의가 필요함

### NOT_INSTALLABLE

- 보도가 없거나 설치 후 통행을 방해함
- 차량·횡단 위험이 높음
- 사유지 문제 또는 구조적 장애가 큼

### REVISIT

- 지도·현장 상태가 불명확하거나 공사 중
- 추가 시간대 관찰이 필요함

## 5. 특히 주의할 후보

- `selection_driver=GAP_LED`: 공백은 크지만 실제 수요가 약할 수 있으므로 보행 관찰 필요
- `route_count_800m`가 작은 후보: 실제 생활 목적지 연결 여부 재확인
- `name=도로명 없음`: 후보 구간과 접근 가능 도로를 지도에서 정확히 확인
- 500m 후보: 공원·산책로 주변의 오래된 벤치 자료가 실제와 다른지 우선 확인

현장조사 결과를 채운 뒤에만 설치 가능성 점수와 최종 후보 순서를 계산한다.
