# 달서구 벤치 설치 우선 검토구간 Evaluation 결과

## 1. 종합 판정

**Share with caveats — 공모전·개인 프로젝트 결과로 공유할 수 있으나 실제 설치 결정에는 바로 사용할 수 없다.**

계산 재현성, 후보 제외 로직, 경로·시설 연결 근거와 민감도 검사는 통과했다. 그러나 경사, 횡단 안전, 보도 폭, 소유권·설치 가능성, 실제 좌석 상태가 포함되지 않았기 때문에 결과는 현장조사 순서로만 사용해야 한다.

## 2. 평가 범위

기준거리별로 다음 18개 조합을 평가했다.

- 계단 포함·제외: 2개
- OD 반경: 500m, 800m, 1,200m
- 수요 가중치: 35%, 50%, 65%
- 공백 가중치: 수요 가중치의 나머지인 65%, 50%, 35%

300m·500m 공백 기준을 나누어 총 36개 순위 조합을 계산했다.

## 3. 핵심 결과

| 항목 | 결과 |
|---|---:|
| 민감도 조합 | 36개 |
| 300m 기준 TOP 20 출현 고유 도로 | 44개 |
| 500m 기준 TOP 20 출현 고유 도로 | 41개 |
| 300m 안정 후보 | 16개 |
| 500m 안정 후보 | 15개 |
| 현장조사 우선표 | 30행 |
| 현장조사 고유 도로 | 29개 |
| Evaluation 자동검증 | 11/11 PASS |

안정 후보는 같은 벤치 기준의 18개 조합 중 12개 이상에서 TOP 20에 포함된 도로다. 이는 설치 적합성이 아니라 **분석 기준 변화에도 순위가 비교적 유지됨**을 의미한다.

## 4. 민감도 해석

### 계단 포함 여부

모든 반경·가중치 조합에서 계단 포함과 제외의 TOP 20이 100% 일치했다. 현재 보행망에서는 계단 처리 방식이 후보군을 바꾸는 주요 요인이 아니었다.

### 수요·공백 가중치

OD 반경을 800m로 고정하면 수요 가중치를 35% 또는 65%로 바꿔도 기준 TOP 20의 85~90%가 유지됐다. 현재 설정 범위 안에서는 가중치 변화에 비교적 안정적이다.

### OD 반경

500m·1,200m 반경으로 바꾸면 TOP 20 유지율이 최저 50%까지 낮아졌다. 후보 결과는 가중치보다 **생활권 반경 선택에 더 민감**하다.

따라서 공모전 결과에서는 800m를 절대적 고령자 보행권으로 표현하지 않고, 500m·800m·1,200m 민감도 결과를 함께 제시해야 한다.

## 5. 후보 근거 검증

Modeling 고유 TOP 후보 39개는 모두 최소 한 종류의 생활 목적지 연결 근거를 갖고 있다.

| 연결 근거 | 후보 수 | 비율 |
|---|---:|---:|
| 버스정류장 | 37 | 94.9% |
| 의료기관 | 28 | 71.8% |
| 노인복지시설 | 19 | 48.7% |
| 공원 | 4 | 10.3% |
| 목적지 근거 2종 이상 | 26 | 66.7% |

좌석 공백이 0인 도로는 후보표에 포함되지 않았다. 300m 기준에서는 수요가 있는 도로 약 80%, 500m 기준에서는 약 98.5%가 좌석 충분 구간으로 제외됐다.

## 7. 결론

현재 분석은 달서구 전체에서 현장조사가 필요한 범위를 29개 고유 도로로 줄이는 **1차 선별 도구**로 적합하다. 다음 작업은 새로운 점수를 추가하는 것이 아니라 이 도로들의 실제 보행환경과 좌석 상태를 확인하는 것이다.
