# 현장조사 입력 화면 사용법

## 화면 열기

프로젝트 루트에서 다음 명령을 실행한다.

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

브라우저 주소창에 다음 주소를 입력한다.

```text
http://127.0.0.1:8765/05_evaluation/field_review_app/index.html
```

## 조사 방법

화면에는 민감도 18개 조합 중 6회 이상 선정된 54개 고유 도로가 들어 있다.
기존에 검토한 29개 판정은 미리 채워져 있으며, 화면을 열면
`추가 검토 25개` 필터가 기본 적용된다.

1. 왼쪽 후보를 누르면 도로 구간으로 확대된다.
2. 필요한 경우 `카카오맵에서 보기`로 로드뷰를 확인한다.
3. 오른쪽에서 종합 판정과 현장 항목을 입력한다.
4. 입력값은 현재 브라우저에 즉시 자동 저장된다.
5. `다음 미검토`를 누르면 아직 판정하지 않은 도로로 이동한다.
6. 검색과 300m·500m·검토상태 필터를 사용할 수 있다.

## 결과 보관

조사가 끝나면 반드시 `완료 CSV 내보내기`를 누른다.

- 파일명: `dalseo_field_review_completed_54.csv`
- 브라우저 자동저장은 같은 브라우저의 임시 작업 보존용이다.
- 브라우저 기록을 지우거나 다른 컴퓨터로 이동하면 자동저장값이 사라질 수 있으므로 CSV를 별도로 보관한다.
- 기존 CSV를 `CSV 불러오기`로 다시 불러와 이어서 작업할 수 있다.
- `백업 JSON`은 보조 백업이며 다음 분석에는 완료 CSV를 사용한다.

진행률이 `54 / 54`가 되면 CSV를 내보내 프로젝트 폴더에 넣는다. 기존
29개를 다시 입력할 필요는 없다. 파일을 넣은 뒤 알려주면 54개 전체의
현장 결과 검증과 2차 우선순위를 다시 계산한다.
