
## 5. 자동으로 덮어쓰는 파일

파이프라인 재실행 시 `03_data_preparation/outputs`와 `03_data_preparation/qa`의 전처리 산출물은 최신 입력 기준으로 갱신된다. 원본 CSV와 수동 검수 파일은 수정하지 않는다.

입력 파일 변경 여부는 `qa/source_manifest.csv`의 SHA-256으로 추적한다.
