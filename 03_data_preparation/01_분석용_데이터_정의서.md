# 달서구 고령자 예상 보행수요 분석용 데이터 정의서

## 1. 문서 목적

이 문서는 Data Preparation 단계에서 생성한 분석용 데이터의 범위, 레코드 단위, 핵심 필드, 포함·제외 원칙을 정의한다.

- 분석 대상: 대구광역시 달서구
- 고령자 정의: 만 65세 이상
- 휴식시설 공급: 공원 내 개별 벤치와 버스정류장 의자만 포함
- 분석 좌표계: EPSG:5179, 미터 단위
- 벤치 공백 기준: 300m와 500m를 Modeling 단계에서 각각 적용
- 표현 원칙: 실제 이동 경로가 아니라 고령자 예상 보행 수요와 예상 보행 경로

이 단계에서는 최단 경로, 경로 중첩도, 벤치 공백, 우선순위 점수를 계산하지 않았다.

| 경로당 | `senior_centers.csv` | 경로당 1개 | 285 | 출발·도착 후보 |
| 노인복지시설 | `welfare.csv` | 시설 원본 1행 | 212 | 출발·도착 후보 |
| 의료기관 | `medical.csv` | 의료기관 원본 1행 | 871 | 도착 후보 |

의료기관 871행은 좌표가 465개 위치로 중복된다. 같은 건물에 여러 의료기관이 존재할 수 있으므로 자동 삭제하지 않았다.

## 3. 공간 산출물

### 3.1 `analysis_points_epsg5179.gpkg`

다음 7개 EPSG:5179 포인트 레이어를 포함한다.

| 레이어 | 내용 |
|---|---|
| `population_origins` | 행정동 고령인구 대표점 |
| `senior_centers` | 경로당 |
| `welfare_facilities` | 노인복지시설 |
| `medical_facilities` | 의료기관 |
| `park_destinations` | 공원 대표점 |
| `bus_stops_demand` | 정류소와 2025 이용량 |
| `resting_seats` | 공원 벤치와 정류장 의자 |

### 3.2 기타 공간 파일

- `admin_dong_population_epsg5179.geojson`: 행정동 경계와 만 65세 이상 인구
- 검수 완료 보행망: `data_external/osmnx_dalseo_walk/qa/dalseo_walk_reviewed_epsg5179.gpkg`

행정동 대표점은 다중 경계 중 면적이 가장 큰 파트의 도형 중심으로 계산했다. 이 점은 실제 고령인구의 미시적 분포를 의미하지 않는다.

## 7. 휴식시설 공급 필드와 정책

| 필드 | 정의 |
|---|---|
| `source_type` | `park_bench` 또는 `bus_stop_seat` |
| `seat_count` | 보고된 의자 수; 공원 개별 벤치는 원본 1행당 1 |
| `supply_status` | 사용 가능 또는 수리 필요 현장 확인 |
| `active_supply` | 접근거리 공급으로 바로 사용할 수 있으면 1 |
| `place_name` | 공원명 또는 정류소명 |

포함 정책:

- 2022년 공원시설물 자료의 달서구 개별 벤치 2,733행
- 2026년 달서구 벤치 자료에서 의자 수가 1개 이상인 버스정류장 436행, 보고 의자 678개

상태 정책:

- 공원 벤치 2,728행은 `AVAILABLE`
- 수리 필요 공원 벤치 5행은 `FIELD_CHECK_REPAIR_NEEDED`, `active_supply=0`

제외·분리 정책:

- 의자 수 0인 정류소는 공급에서 제외
- 2026년 공원별 벤치 합계 155행은 실제 개별 위치가 아니므로 거리 공급에서 제외
- 공원별 합계는 `park_bench_aggregate_reference_only.csv`에 보존
- 쉼터, 실내 의자, 일반 시설 좌석은 포함하지 않음

## 8. 보행망 시나리오 필드

`walk_edge_analysis_flags.csv`는 수동 검수 결과를 훼손하지 않고 두 시나리오용 플래그를 제공한다.

| 필드 | 정의 |
|---|---|
| `qa_effective_route_action` | 자동·수동 검수 결합 최종 판단 |
| `routable_steps_included` | 계단 포함 시나리오에서 사용 가능 |
| `routable_steps_excluded` | 계단 제외 시나리오에서 사용 가능 |
| `requires_modeling_penalty_review` | Modeling에서 비용 정책 검토 필요 |

`EXCLUDE`, `EXCLUDE_CONSERVATIVE`, `NO_ROUTE_COMPONENT`는 두 시나리오에서 제외한다. 계단과 산책로 비용 배수는 이 단계에서 임의 설정하지 않았다.

## 9. 분석에서 제외한 자료

| 자료 | 처리 | 사유 |
|---|---|---|
| 노인일자리사업 | Modeling 입력 제외 | 주소·좌표가 없어 공간 목적지 생성 불가 |
| 서구 벤치 | 1차 분석 제외 | 달서구 단일 지역 범위 유지 |
| 2026년 공원 벤치 합계 | 거리 공급 제외, 참고표 보존 | 공원 대표점에 합계 수를 배치하면 접근거리 왜곡 |
| ID 미확정 정류소 6개 이용량 | 0 또는 결측 상태 유지 | 20m 초과 최근접 ID를 강제 연결하지 않음 |

## 10. 추적성과 검증 파일

- `qa/source_manifest.csv`: 입력 경로, 파일 크기, SHA-256
- `qa/validation_checks.csv`: 자동 검증 결과
- `qa/output_quality_metrics.csv`: 행 수, 좌표 중복, 스냅 거리 등
- `qa/review_network_snap_over_100m.csv`: 최근접 노드 100m 초과 점
- `qa/review_outside_admin_boundary.csv`: 행정동 경계 밖 또는 경계 판정 실패 점
- `outputs/senior_center_coordinate_corrections.csv`: 경로당 좌표 보정 이력
- `outputs/bus_stop_id_crosswalk_audit.csv`: 정류소 ID 연결 전체 감사표
