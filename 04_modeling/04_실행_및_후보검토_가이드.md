# Modeling 실행 및 후보 검토 가이드

## 1. 전체 Modeling 재실행

프로젝트 루트에서 다음 명령을 실행한다.

```bash
python3 -m pip install -r 04_modeling/requirements-modeling.txt
python3 04_modeling/scripts/model_expected_walk_and_bench_gaps.py
```

현재 작업 환경의 번들 Python으로 재현 노트북까지 실행하려면 다음 명령을 사용한다.

```bash
/Users/moon/.cache/codex-runtimes/codex-primary-runtime/dependencies/python/bin/python3 \
  04_modeling/scripts/execute_modeling_notebook_stdlib.py
```

실행 성공 여부는 `04_modeling/qa/modeling_summary.json`의 `status`와 `04_modeling/qa/modeling_validation_checks.csv`를 확인한다.

## 2. 후보 지도 크게 열기

프로젝트 루트에서 로컬 서버를 실행한다.

```bash
python3 -m http.server 8765 --bind 127.0.0.1
```

브라우저 주소창에 아래 주소를 입력한다.

```text
http://127.0.0.1:8765/04_modeling/outputs/priority_candidates_review.html
```

지도는 브라우저 창 전체를 사용한다. 왼쪽에서 전체·300m·500m 후보를 필터링하고, 후보 카드를 클릭하면 해당 도로로 확대된다. 팝업의 `카카오맵에서 보기`를 누르면 위성·로드뷰 기반 수동 확인을 이어갈 수 있다.

## 3. 후보별 확인 순서

1. `안정성 4/4` 또는 높은 안정성 후보를 먼저 본다.
2. 800m 경로 중첩과 최대 좌석거리를 함께 본다.
3. 300m·500m 중 어떤 기준에서 후보가 됐는지 확인한다.
4. 도로명, 보도 유무, 횡단 필요성, 경사, 그늘, 설치 폭을 확인한다.
5. 기존 좌석이 실제로 존재하고 이용 가능한지 확인한다.
6. 설치 가능·불가·추가조사로 현장 판정을 기록한다.

## 4. CSV로 전체 후보 확인

- 검토용 39개 고유 후보: `04_modeling/outputs/priority_edge_candidates_unique_review.csv`
- 조합별 TOP 20: `04_modeling/outputs/priority_edge_candidates_top20.csv`
- 전체 점수 후보: `04_modeling/outputs/priority_edge_candidates_all.csv`

공간 프로그램(QGIS 등)에서는 `priority_edge_candidates_top20_epsg5179.geojson`을 열고 좌표계를 EPSG:5179로 사용한다.

## 5. 검토 시 반드시 유지할 표현

- 적절: “고령자의 예상 보행 수요가 높은 구간”
- 부적절: “실제 노인 이동 경로”
- 적절: “신규 벤치 설치 우선 검토 구간”
- 부적절: “최종 벤치 설치 위치”
